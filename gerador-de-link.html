Gerador de link personalizado

Uso interno da Cibele Matozo Fotografia — não é para enviar esta página ao cliente, apenas o link que ela gera abaixo. Use depois de negociar as condições de pagamento com o cliente, antes de mandar o formulário.

Ficou grande? Cole este link em tinyurl.com ou is.gd (gratuitos, sem cadastro) para gerar uma versão curta só para este cliente.

Se deixar o campo de condições em branco, o link gerado é igual ao link acima — o cliente verá o campo de condições especiais normal, como opcional, para preencher se quiser.

Na primeira vez que usar, cole a URL real da sua página no campo "Link da página do contrato" acima (ela fica salva no navegador para as próximas vezes, mas confira sempre que copiar este arquivo para outro computador).
